# Поздрави за клиенти (Android)

Лично приложение за напомняния и поздрави към клиенти: рождени дни, имени дни, годишнини от покупката на имот и семейни празници. Изпраща поздрави през Viber, имейл и SMS.

- Данните се пазят само на телефона (вътрешна памет на приложението, без резервно копие в облака, без достъп до интернет).
- Известие в избран час в деня на празника (и по желание предния ден).
- Импорт и експорт на клиенти чрез CSV.

Компилира се автоматично от GitHub Actions при всяка промяна в клона `android-app`. Готовият файл е в release `pozdravi-app`.
